# スペルれんしゅう

こども向けの英単語スペル練習アプリです。単語を聞いて、文字カードを並べて（またはキーボードで）答えます。

- 公開URL: https://tagam.github.io/spelling-practice/
- `main` にマージすると、GitHub Pages に自動で反映されます（1分ほど）。反映直後に古い画面が出たら、少し待ってから再読み込みしてください。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | アプリ本体（画面・動き） |
| `lists.js` | 単語リスト。毎週の更新はこのファイルだけ |

## 使うリストの決まり方

- アプリはいつも `lists.js` の `SPELL_LISTS` の**いちばん上**のリストを使います。こどもが切りかえないよう、画面にリストの選択はありません。
- ほかのリストを開きたいときは、URL の後ろに `?list=ID` を付けます（おとな用）。知らない ID のときは、いちばん上のリストになります。

| リスト | URL |
|---|---|
| 最新の週のテスト | https://tagam.github.io/spelling-practice/ |
| スペリングビー（50語） | https://tagam.github.io/spelling-practice/?list=spellingbee-2026 |

## 毎週のリストの足し方

月曜に届く範囲のお知らせ（約15語）をもとに、`SPELL_LISTS` の**いちばん上**に新しいリストを1つ足します。古い週のリストは消さずに残しておけば、`?list=ID` で開けます。

```js
var SPELL_LISTS = [
  {
    id: "2026-10-27",              // ?list= で使う名前。テストの日付にする
    name: "10/27（か）の テスト",    // ホームに出る名前
    lower: true,                   // true なら小文字で練習
    setSize: 15,                   // 1回の問題数
    groups: [                      // カテゴリ。この順番で出題する
      {
        title: "きせつの ことば",
        words: [
          {w:"spring", m:"はる（はなが さく きせつ） 🌸"}
          // ...
        ],
        hint: "はる、なつ、あき、ふゆ、きせつは 4つ！",   // 「」のコツ（なくてもよい）
        examples: [                                      // 「おぼえかたの コツ」画面の例文
          {en:"Spring, summer, autumn, winter — four seasons!", ja:"はる、なつ、あき、ふゆ、きせつは 4つ！"}
        ]
      }
      // ...
    ],
    cards: [                       // この週のガチャで集めるカード
      {e:"🐶", n:"いぬ", r:0}      // r: 0=ノーマル 1=レア 2=キラキラ（キラキラは最後に出る）
      // ...
    ]
  },
  // ↓ 前の週のリストやスペリングビーはそのまま
];
```

- `groups` の代わりに `words` だけを書くこともできます（カテゴリ・コツなし。スペリングビーはこの形）。
- 答えたあとには、その単語が出てくる `hint` → その単語が出てくる `examples` の例文 → カテゴリの `hint` の順に、1つを選んで表示します。
- 2語の単語（`salt water` など）は、スペースのところをはじめから空けて出題します。
- 小文字のリストでも、キーボードで答えたときに大文字・小文字の違いはまちがいにしません。

## ガチャとカード

- テストを最後までやると、ガチャ券が1枚もらえます（「まちがえた もんだいだけ れんしゅう」「まちがえたのだけ もういちど」も対象）。
- カードはかぶりなしで、`cards` の枚数ぶんガチャを回すと必ず全部そろいます。そろうと「コンプリート！」と出て、それ以降はガチャ券を配りません。
- ガチャ券と集めたカードは、リストごとに分かれています。
- 枚数の目安は下の「カードの枚数の決め方」を参照。

## 保存されるデータ

成績・ガチャ券・集めたカード・設定は、その端末のブラウザ（localStorage）に保存されます。別の端末やブラウザとは共有されず、ブラウザのデータを消すと消えます。

## カードの枚数の決め方

- ガチャ券は今のまま、テストを最後までやるたびに 1枚（「まちがえたのだけ もういちど」も対象）。1日に何回でも引ける。
- **カードの枚数は週ごとに決める**。テストの曜日がずれる週や休みがある週もあるので、その週に練習する日数と、1日にやる回数の見込みから決める。最後の 1まいはキラキラ。
- ふだんの週の練習のしかた（紙のときと同じ）：1日に 15問を 1回やり、まちがえた単語だけを全部正解になるまでやり直す（最大 3回）。テストの前日（ふだんは木曜）は、おとなが読み上げて紙で書き取りテストを 1回やる。
